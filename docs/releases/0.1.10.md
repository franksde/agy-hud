# 0.1.10 验证记录

日期：2026-09-04。发布基线：`c54f28d`。触发来源：GitHub issue #13（状态栏图标显示为方块）。

## 问题定性

图标不是资源加载失败，而是终端字体缺字形。`src/statusline.ts` 中的四个图标位于 Unicode 私有区（U+EE9C 模型、U+F0A3 套餐、U+E725 分支、U+F07C 目录），只有打过 Nerd Font 补丁的字族才带；配额重置箭头是标准 Unicode U+21BB，任何字体都有。报告截图中「图标全为 `[?]`、`↻` 正常」即此现象的特征，插件行为本身正确。

真正的缺陷在文档与可发现性：Nerd Font 依赖此前只在 README 的 AI Agent 章节出现过一行，手动安装的用户看不到。

## 行为与验证

- 新增 `doctor` 子命令：Node 版本、CLI 状态栏实际接入的命令、生效的配置文件与解析后的 `show_icons`、识别到的终端、是否 SSH 会话、启发式 Nerd Font 扫描、图标探针。只读，不写磁盘。
- `doctor --json` 输出同一份报告的机器可读形式，供 agent 在安装后自查。
- 字体扫描在两个方向上都不作为判据：已安装的 Nerd Font 未必是终端在用的字族；Ghostty、WezTerm、kitty 自带字形回退。本机即为后者的实例——扫描报 `not-found`，而图标渲染正常。TTY 协议不回传已绘制的字形，方块与字形同占一列，`ESC[6n` 也无法区分，因此探针必须由人来读，代码与文档措辞均按此约束表述。
- 配置优先级修正：`configPaths()` 中 bundle 旁 / 插件根目录的 `config.json` 优先于 `~/.config/agy-hud/config.json`。`doctor` 建议的修改路径必须是当前生效的那一个，否则用户会写下一个被压住的文件。此问题在本地真实安装环境下复现后修复。
- 隐私：人读输出中家目录路径缩写为 `~/…`，去掉账户名——该输出正是用户会贴进 issue 的内容，而 README 隐私章节明确要求不要提交本机路径。`--json` 保留绝对路径，面向同机 agent。
- 文档：中英文 README 各新增「Icons Render As Boxes / 图标显示成方块」章节，运行要求补充字体依赖，CLI 与配置章节接入 `doctor`，隐私章节说明 `doctor` 的数据边界；「For AI Agents / 面向 AI Agent」整章重写为「先发探针提问 → 报方块则装前写配置 → 安装 → `doctor --json` 验收」，并明确要求 agent 不得代用户安装字体（装字体不改终端字体设置则无效，SSH 下在远端装更是完全无效）。
- `AGENTS.md` 新增一节，记录字体检测只能是启发式的原因，防止后续将扫描结果提升为判据或把装字体加入安装流程。

## 审查后修复

r2 报出 9 项，逐条核实后接受 7 项、部分接受 1 项、否定 1 项：

- `homedir` 为 `/` 时不再缩写。`/` 作为前缀会匹配任何绝对路径，等于把整个文件系统当作家目录。
- 缩写覆盖命令串中的家目录前缀。`/statusline` 可被配成 `node <path> statusline`，此前只判断整串开头，用户名会原样进入报告——恰好绕过本次的脱敏修复。
- `dirname` 对根目录下的文件返回 `/` 而非原路径，避免生成 `mkdir -p <配置文件>`。
- 终端识别增加 kitty 与 Alacritty。两者均不设 `TERM_PROGRAM`，改用其自有变量与 `TERM` 识别，`TERM_PROGRAM` 仍然优先（多路复用或 ssh 会带来陈旧的 `TERM`）。此前这两个分支是死代码。
- `fc-list` 改为只取 family 并提高输出上限。无参数调用在字体多的机器上可能超出默认 1 MB 缓冲，而该失败会被吞掉并误报为「无法扫描」。
- 字体扫描行折行并限制单个字体名长度；SSH 会话下标注「扫描的是本机，不是绘制字形的那台」。
- XDG 优先级：`doctor` 不再从 `configPaths` 里猜用户级路径，改由 `src/main.ts` 的 `userConfigPath()` 明确告知，自定义 `XDG_CONFIG_HOME` 因此得到尊重。r2 将其定性为 bug 并不准确——该路径仅在无任何配置文件时使用，此时写哪一份都会生效；但让 doctor 猜路径本身是缺陷，故按此修正。
- 未采纳 r2 的 L-9：它称 README 第 2 步「推迟到第 5 步」形成闭环断裂，实际第 5 步末段已写明让用户自行运行不带 `--json` 的 `doctor` 看探针。该提示位置偏后，已改为在第 2 步直接给出，不作为缺陷计。

补测过程中另发现一项 r2 未报出的缺陷：`nerdFontPattern` 以 `\s*` 分隔两个单词，匹配不到 `Hack-Nerd-Font-Regular.ttf` 这类连字符命名，已改为可选标点分隔。
