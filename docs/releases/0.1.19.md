## 行为

- `Orchestrator (Argon)` 读取共享 Gemini 配额桶而非 Argon 独立周额度桶（`d19a257`）。
- 未消耗占位时间戳兼容：在 `src/quota.ts` 导出 `isUnsetResetTime`（精确匹配 `1970-01-01T00:00:00Z` 与 `0001-01-01T00:00:00Z`），供 `formatResetCountdown` 与 `src/statusline.ts` 复用；`liveCachedBuckets` 保留 `remaining_fraction === 1` 的占位桶为有效 `100%` 读数（无倒计时），过滤越界余量、非字符串/非占位负时间戳及已消耗占位桶；`formatResetClock` 对非字符串与非正时间戳返回空串，避免输出假时钟或抛 `TypeError`。
- 跨窗口与新鲜度保护：`src/main.ts` 在调用 `queryUsage()` 前记录 `startedAt` 作为 `/usage` 缓存时间戳；`mergeQuotaBuckets` 要求未消耗占位缓存仅在 `payloadReset <= cacheTime <= now` 时替换已结束 payload；已消耗占位 payload（无正 `reset_in_seconds`）让位给有有效未来 `reset_time` 的缓存；双侧均为已消耗且未过期窗口时，若 payload 的正 `reset_time` 晚于缓存超过 60 秒（如服务端中途全局重置），采用新窗口 payload，且保持单向以防跨账号共享缓存抬高当前账号余量。
